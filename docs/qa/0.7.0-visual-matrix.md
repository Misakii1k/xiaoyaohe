## Automated assertions

- Every primary route has one application shell and one visible level-one heading.
- The document never grows wider than the configured viewport.
- On narrow layouts, the content scroll region ends before bottom navigation; on wide layouts, it remains within the viewport beside side navigation.
- New medication starts with one final save command and can append a blank draft.
- Opening batch time editing then changing routes removes the dialog and focuses the next page heading.
- Screenshots are attached to the Playwright run under `output/playwright/`; they are evidence artifacts, not source assets.
