# 小药盒 0.9.6 更新说明

这次把用药提醒从「每种药各响一次」改成了**按时段聚合的整体提醒**：每天早上、中午、晚上、睡前各发一条，按你的实际服药节奏来，不再被同一时间的多种药刷屏。

## 你能直接感受到的变化

- 提醒改为按时段聚合：同一天的早上/中午/晚上/睡前各只有一条整体提醒，标题会说明是哪个时段（例如「🔔 早上服药时间到了」），正文逐行列出该时段要吃的每种药和用量。
- 时段级设置代替了单药设置：在「设置 → 时段提醒设置」里统一管理每个时段的整体提醒时间、提醒方式（增强通知 / 短时全屏 / 持续全屏）和重复策略（未确认时每几分钟再提醒、最多重推几次、超过多久通知照护者）。
- 每种药自己的精确提醒时间仍然保留，用于记录与库存归因；药品编辑页不再单独设置提醒方式，改为提示该药属于哪个时段。
- 全屏服药页升级为可滚动的多药列表：每行一种药，可单独「已服/跳过」，底部提供「全部已服用」和「10 分钟后提醒」。
- 原生通知按钮按组提供「全部已服用 / 10 分钟后提醒」，一次确认整组药物；已服/跳过操作不会丢失（通知操作队列改为非破坏性，处理成功后才确认移除）。
- 小助手新增「设置时段整体提醒」能力，可一次设置某个时段或全部时段的整体时间、方式与重复策略；查看药品清单时也会返回各时段的整体提醒设置。
- 时段内不同药的提醒时间或方式不一致时，设置页会提示「待复核」，请确认一个统一的整体时间与方式后再继续。

## 安全和稳定性

- 「全部已服用」在单次数据库事务里批量记录整组药物，任一条失败（如药品已过期）则整批回滚，不会只记录一半。
- 提醒操作队列改为非破坏性：应用启动重放时逐条处理，成功后才确认移除，崩溃或被杀进程不会丢操作；重复处理已有记录的动作是幂等的，不会重复扣减库存。
- 修复了取消服药记录时库存可能回写旧值的问题：撤销现在以库存日志为准恢复，不会把恢复前的剩余量覆盖回去。
- 时段复核标记在保存药品/规则后自动重算，不会静默归一化时段内的时间差异。

## 还需注意

- 时段提醒设置是设备本地配置，不随局域网同步到其他设备；药品的提醒时段本身仍会同步。
- 全屏提醒仍受 Android 系统权限和厂商后台策略影响；权限不足时，应用会提示可能降级为增强通知，不会擅自更改系统设置。
- 本次自动化环境没有可用的 ADB 设备，因此未执行真机 instrumentation；已完成 Web、单元、四视口浏览器和 Android Release 构建验证。
