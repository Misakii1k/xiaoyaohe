# 小药盒 1.0.11 发布说明

本次更新重点提升了页面切换的流畅度，增加了手机存储与缓存清理功能，并补充了主流手机品牌的后台提醒运行指引。

## 新增与改进

- **界面切换更顺畅**：在今日服药、药品管理、用药记录和设置这几个主要页面之间切换时，页面会保持已加载的内容和浏览进度，不需要重新加载，减少等待。
- **存储与缓存清理**：在设置页面中增加了存储空间查看功能，可以直观查看用药数据、药品照片以及临时缓存的占用情况，并支持一键清理临时缓存，释放手机存储空间。
- **主流手机后台提醒指引**：在用药提醒设置中，增加了小米、华为、OPPO、vivo 等主流手机品牌的后台自启动与电池优化指引，并提供快捷跳转按钮，方便调整系统设置，保证锁屏时准时提醒。
- **药品编辑与照片优化**：改进了添加和编辑药品时的照片处理逻辑，减少手机内存消耗，让录入和编辑药品更加顺手。
