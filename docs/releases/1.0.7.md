# 小药盒 1.0.7 发布说明

本次更新整理了设置页与药品列表的排版，去除了重复的菜单项，并改进了批量管理时的操作体验。

## 设置页

- 去除设置页顶部重复的列表和右上角齿轮按钮，所有功能按类别直接展示在主页面中。
- 为各个设置项配上了不同颜色的图标，在深色模式下也会同步调整色彩。
- 重新整理了「关于小药盒」卡片，居中展示药盒标志、当前版本和核心功能说明。

## 药品页

- 将「添加药品」按钮固定在屏幕右下角，滑动列表时不会再跟着上下移动。
- 调整了顶部「全部药品、近期使用、需补充」三个卡片的图标背景，去除原先的实心圆圈，改为柔和发散的光晕效果。

## 批量管理

- 每种药品改为独立的卡片展示，左右两列之间有了清晰的间隔与边框。
- 加深了未选中时复选框的边框颜色，在白色卡片背景上更容易看清。
- 支持点击卡片任意位置切换勾选，不再需要精准点击小方框。
- 精简了屏幕底部的操作栏，将四个操作按钮合并为单行展示，去除了重复的选中数量提示，避免遮挡药品内容。
