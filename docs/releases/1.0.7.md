# 小药盒 1.0.7 正式版发布说明

小药盒迎来 1.0.7 版本。本版本系统性重构设置页平铺架构并重绘全套五彩微拟物图标，将药品页「添加药品」稳定悬浮于右下角，升级三大统计指标为通透柔和环境光晕，并彻底根治批量管理界面的卡片融合、复选框不易识别与底部操作栏大面积遮挡缺陷。

## 主要更新

- **设置页纯平铺分类卡片与全量五彩微拟物图标重绘**：
  - 彻底清除顶部 6 行冗余菜单列表与右上角齿轮菜单，确立纯平铺分类卡片群架构；
  - 参考原高保真彩底微拟物图标体系，为全量 11 个设置项重绘 32x32px、圆角 8px 的专属浅彩底色与高饱和前景矢量图标，浅色与深色模式自适应适配；
  - 关于小药盒重塑为居中品牌展台：搭载 56px 渐变药盒浮动图标、版本号药丸徽章、2x2 精致特性磁贴卡片与柔和免责声明。
- **药品页三大指标环境光晕与「添加药品」右下角停靠**：
  - 彻底清除「全部药品、近期使用、需补充」指标卡图标下方的实色圆盘底色（圈），升级为 3 级径向渐变的多层柔和发光环境光晕；
  - 将「+ 添加药品」FAB 移入底部操作坞，精准悬浮于屏幕右下角，非按钮区域支持手势穿透，兼顾便捷性与列表可视范围。
- **批量管理页面针对性排版全面根治**：
  - 独立微卡片单元：双列卡片从原本挤在同一大白底框升级为带独立背景、独立边框、圆角与微投影的独立卡片；
  - 复选框清晰可见：未选状态下边框由极浅透明色加深为高对比度微深色边框（`#94a3b8`），彻底解决白底融化隐形；
  - 整卡点击勾选：点击微卡片任意区域均可直接切换选中状态；
  - 底部操作坞单行极简瘦身：移除内部重复的「已选 0 种」，将 4 个操作按钮精简为 48px 超薄单行胶囊浮动工具栏，杜绝遮挡屏幕。
