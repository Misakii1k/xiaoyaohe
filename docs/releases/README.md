# 发布说明

每次准备发布时，在本目录新增与应用版本同名的 Markdown 文件，例如 `0.9.4.md`。

说明只写用户能直接感受到的变化，使用日常说法，不罗列内部类名、脚本名或实现细节。内容至少回答三件事：哪里更好用了、哪里更安全或更稳定、哪些事情仍需要真机确认。

`npm run release` 会在构建前检查当前版本对应的说明文件；缺少文件时立即停止，避免只有安装包、没有可读更新说明。
