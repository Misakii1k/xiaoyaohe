# 小药盒 0.9.4 更新说明

这次主要把照片、更新安全、网页版体验和手机适配做得更稳，也补上了方便排查问题的工具。

## 你能直接感受到的变化

- 药盒照片不再被硬挤成正方形，横图、竖图都会按原来的比例显示；换图和压缩后也不容易变形。
- 小助手和各个页面改成需要时再加载，打开应用更轻，平时没用到的内容不会一股脑塞进首屏。
- 网页版补齐了安装入口、更新刷新和吃药提醒的降级提示；浏览器不支持后台提醒时，会直接告诉你该怎么处理，不会假装已经提醒成功。
- 今日、药品和设置等常用页面加强了深色模式、刘海屏、底部手势区、横屏和放大显示适配，按钮与文字更不容易被挡住。

## 安全和稳定性

- 从局域网收到的新安装包会先核对包名、版本和签名，发现安装包损坏、版本不对或不是同一个签名时会直接拦住，不让它进入安装步骤。
- 语音识别代理默认拒绝陌生网页调用，并改进限流；网页保存密钥时会明确说明风险，清空后也不会留下旧值。
- 页面偶尔加载失败时不再把生硬的报错直接丢给你，而是显示可重试的说明；原始问题只进入已经脱敏的本机诊断记录。
- 提醒、家庭同步和照片处理遇到可恢复的小故障时，会留下最近的脱敏记录，设置页可以查看、复制或清空，方便定位问题，又不会记录密钥和完整用药内容。

## 还需注意

- Android 安装、系统级提醒、旋转和异形屏最终效果仍建议在实际手机上再走一遍；本次自动验证环境没有可用的 ADB 设备。
- 家庭同步收到的 APK 仍只建议来自你自己的已升级设备；应用会做安装前校验，但不要从不认识的设备主动接收文件。
