# 小药盒 0.9.5 更新说明

这次重点完善库存录入、图片多药识别、语音录入界面和小助手的提醒方式管理，让补货与批量处理更准确、更省步骤。

## 你能直接感受到的变化

- 库存页新增明确的“添加库存”入口，补货会在当前剩余数量上累加，并实时显示“当前剩余 + 本次新增 = 入库后剩余”；盘点修改和标记用完仍保持独立。
- 智能录入现在可以从一张药盒合照、药单或购药票据中识别多种药，也支持一次选择多张图片；识别到多少种药就保留多少条供你核对。
- 智能录入会区分“买了、补货、入库”等累加操作与“还剩、盘点为”等绝对设置操作，每条结果都可以在保存前修改。
- 多个未登记药品会一起进入批量建档，不再只保留第一种，识别到的初始库存也会随草稿保留下来。
- 库存语音录入面板重新适配小屏、短屏、系统安全区和软键盘，操作按钮不会再被底部导航或小助手遮住。
- 小助手新增提醒方式管理能力，可将一个、多个指定药品或全部药品批量切换为增强通知、短时全屏或持续全屏。

## 安全和稳定性

- 批量提醒方式修改会先统一确认，再以单次数据库事务执行；任一目标无效时整批停止，避免只修改一部分，完成后只统一重排一次提醒。
- 库存批量核对采用精确优先和唯一模糊匹配；遇到多个相似药名时会要求手动确认，不会静默选中第一条。
- 库存条目逐项读取最新数据并使用原子更新；补货不会覆盖并发更新的库存资料，失败重试也不会再次累加已经成功的条目。
- 关闭语音面板或离开页面时会停止识别并取消正在进行的智能解析，避免后台回调继续修改已关闭的界面。

## 还需注意

- 全屏提醒仍受 Android 系统权限和厂商后台策略影响；权限不足时，应用会提示可能降级为增强通知，不会擅自更改系统设置。
- 本次自动化环境没有可用的 ADB 设备，因此未执行真机 instrumentation；已完成 Web、单元、四视口浏览器和 Android Release 构建验证。
