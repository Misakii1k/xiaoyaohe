# 小药盒 0.9.13 更新说明

本次更新将用药提醒提升为全屏呈现，并加强了多任务界面的防误关闭保护。

## 主要更新

- **到点自动全屏**：提醒到点时自动弹出全屏服药页面（通过全屏意图、应用主动拉起与前台服务多重路径保障），覆盖前台使用、后台运行、锁屏与灭屏状态。此前仅显示顶部通知的模式已统一调整为全屏呈现。
- **多任务防误关闭**：全屏服药页面运行在独立任务中，且不进入系统最近任务列表。在多任务界面清理主应用卡片不会关闭当前提醒页面，配合常驻前台服务保证提醒持续生效。
- **提醒方式选项调整**：三种提醒方式均在到点时全屏呈现，区别在于页面的保留时长：分为「不自动收起」（默认，需要完成操作）、「10 秒收起」和「60 秒收起」。
- **通知调整为常驻**：提醒通知调整为常驻状态，无法通过下拉通知栏划除，需通过「已服用 / 跳过 / 10 分钟后提醒」按钮或全屏页面处理。

## 注意事项

- Android 14 及以上系统首次使用时，请在系统设置中允许「全屏提醒 / 显示在其他应用上层」权限。未授权时提醒会自动降级为顶部通知（仍带操作按钮）。
- 部分手机厂商的后台清理策略可能终止进程，建议将小药盒加入电池优化白名单（设置页提供跳转入口）。
