# 小药盒 0.9.13 更新说明

这一版把用药提醒的力度再抬一级：到点必全屏、想关关不掉。

## 你能直接感受到的变化

- **到点自动全屏，不再只是顶部通知**：无论应用停在哪个页面、在后台、锁屏还是灭屏，提醒到点都会自动弹出全屏服药页（全屏意图 + 主动拉起 + 前台服务三重路径兜底）。此前"增强通知"模式只弹顶部通知，现在三种提醒方式到点全部自动全屏。
- **多任务里划不掉**：全屏服药页现在运行在独立任务中且不进入最近任务列表——上滑进入多任务时看不到它，划掉应用卡片也不会把它带走；配合常驻前台服务，提醒在处理完成前无法被"上滑强杀"。
- **提醒方式选项更名**：三种方式现在都到点全屏，区别只在全屏页保持多久——「不自动收起」（默认，必须完成操作）/「10 秒收起」/「60 秒收起」。
- **通知不可随手划掉**：提醒通知改为常驻，下拉通知栏也无法滑掉，只能通过「已服用 / 跳过 / 10 分钟后提醒」或全屏页完成。

## 还需注意

- Android 14+ 首次使用请在系统设置中允许「全屏提醒/显示在其他应用上层」；未授权时到点提醒降级为顶部通知（仍不可划掉、带操作按钮），设置页会给出引导。
- 部分厂商的"一键清理"类按钮仍可能终止进程，建议把小药盒加入电池优化白名单（应用内设置页有入口）。
