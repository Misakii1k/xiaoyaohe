# 小药盒 1.0.10 发布说明

本次更新为用药提醒加入了专属音乐《晨间活力》，并支持在设置中自由切换与试听。

## 新增与改进

- **专属用药提醒音乐**：全屏服药提醒默认采用轻快温和的《晨间活力》专属音乐，声音清爽柔和，唤醒更舒适；响铃时会自动暂停手机后台正在播放的声音，提醒结束后自动恢复。
- **提醒铃声自由选择**：在设置页的提醒设置中，增加了用药提醒铃声选项，可以在“晨间活力（专属推荐）”与“系统默认闹钟”之间自由切换。
- **支持在线试听**：设置页面内提供一键试听按钮，无需等待提醒到点，随时可以提前试听音乐旋律。
- **轻量更新与稳定性改进**：优化了更新包的校验和检测流程，提升日常使用的稳定性。
