# 小药盒 0.9.9 更新说明

这次给全屏用药提醒换上了全新的液态玻璃视觉，并新增「扫码解除强制提醒」——把提醒关掉这件事，变成必须先起身走到贴二维码的地方扫一下码才能做到。

## 你能直接感受到的变化

- **全屏服药提醒全新设计**：大号实时时钟、呼吸状态指示灯、柔光渐变背景、渐变主按钮与玻璃质感胶囊按钮；到点自动收起的倒计时直接显示在按钮下方。
- **扫码解除强制提醒（可选）**：在 设置→系统通知 里开启后，需要先「查看解锁二维码」，截图打印贴到药箱、冰箱门等远离床的位置。此后全屏提醒必须扫到这个码才会出现「已服用 / 贪睡 / 跳过」按钮，防止睡迷糊时随手关掉提醒。
  - 锁定状态下，通知栏/锁屏通知上的快捷按钮会被移除，只能进入全屏页扫码解锁。
  - 扫码时使用手机相机，应用会请求相机权限；取景期间倒计时暂停，不会扫到一半被自动关闭。
  - 可以随时在设置里重新生成解锁码（旧码立即作废）或关闭该功能。

## 安全和稳定性

- 解锁比对完全在本机完成：二维码内容只用于本地一致性校验，不联网、不上传。
- 增强通知（非全屏模式）在开启扫码验证时也会升级为全屏拦截页，保证验证不被绕过。
- 若开启了扫码验证但相机权限被拒绝，全屏页会给出明确的引导提示，不会静默卡住。

## 还需注意

- 「扫码解除」仅对 Android 手机 App 的原生提醒生效；网页端无此能力。
- 开启或关闭该功能后，下一次提醒调度（或手动重启应用）即按新规则生效；已排程的当天提醒可在设置里通过任一开关操作触发重建。
- 本次自动化环境没有可用的 ADB 设备，因此未执行真机 instrumentation；已完成 Web、单元、四视口浏览器和 Android Release 构建验证。扫码流程请在真机上用测试入口（系统通知 → 测试全屏提醒）自测一次。
