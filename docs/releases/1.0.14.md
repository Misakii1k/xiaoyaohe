# 小药盒 1.0.14 发布说明

本次更新重点解决了用药提醒到达设定时间后未能全屏弹出、仅停留在通知栏消息的问题，同时修复了提醒响铃无声音只有手机振动的情况，让用药提醒能够像闹钟一样准时响铃并全屏唤醒。

## 新增与改进

- **提醒响铃声音恢复正常**：修复了专属提醒音乐《晨间活力》在部分手机上无法正常发声的问题。现在到点时音乐会正常循环播放，并且在响铃前会自动检查手机的闹钟音量，即使此前不小心把闹钟音量滑到了静音，软件也会恢复到安全音量播放，确保在静音或振动模式下也能准时听到提醒。
- **支持到点直接全屏弹出**：改进了系统提醒与屏幕唤醒机制。当用药时间到达时，软件会主动唤醒屏幕并拉起全屏服药界面，避免提醒信息被系统压制在通知栏角落而遗漏服药。
- **全屏与悬浮显示权限双向指引**：在设置页的提醒设置中，新增了针对全屏弹窗与悬浮显示的权限状态检测。如果手机系统限制了后台全屏弹出，设置页会清晰提示具体缺少哪项权限，并提供一键前往系统设置开启的按钮，方便大家快速配置。
