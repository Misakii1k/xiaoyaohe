# 小药盒 1.0.0 正式版发布说明

小药盒迎来 1.0.0 正式里程碑版本。本版本带来了全新重构的 3D 拟物液态微质感图标系统与环境光色彩弥散效果，完成 Web 端 (PWA) 与 Android 端协同上线，并支持 0.3 秒云端极速通道更新检测。

## 主要更新

- **全新 3D 拟物液态微质感图标与专属环境色彩弥散**：
  - 重构全套 9 款 Studio 级 3D 拟物视觉资产（彩虹亚克力药盒、天蓝用药规划手册、珊瑚红靶向徽章、丁香紫磨砂药瓶、薄荷青时钟药丸、急救药箱、晶莹双色胶囊、智能分药机与立体亲和头像）。
  - 采用纯净透明背景与边缘抗锯齿抠图工艺，结合 CSS 多层径向渐变（Radial Gradient）与动态投影（Drop Shadow）实现向周围柔和弥散的氛围光晕，完美契合液态玻璃视觉语言与明暗主题。
- **0.3 秒云端极速通道更新检测**：
  - 引入毫秒级静态更新探测通道（`version.json` 极速直链与多源 CDN 回退），更新检测耗时由原先的数十秒骤降至 0.3 秒内，无需等待繁重网络扫描。
  - 保留局域网多设备节点扫描与 GitHub Releases 阶梯回退能力，离线与弱网场景同样兼顾。
- **Web 端 (PWA) 生产环境正式部署**：
  - 基于 Cloudflare Pages 实现私有仓库静态站点自动化部署，构建命令与相对路径资源完全解耦。
  - 完整支持离线缓存、桌面及手机 PWA 添加至主屏幕、IndexedDB 本地持久化与扫码用药交互。
- **全屏沉浸式用药防误触屏障与音频闭环**：
  - 支持沉浸粘性全屏手势拦截（Immersive Sticky）与屏幕固定（LockTask），阻断误滑桌面。
  - 引入全局单例音频控制器，杜绝全屏闹钟响铃叠加，提供稳固按时的服药提醒。

## 使用建议

- Android 用户可通过应用内「检查更新」按钮体验 0.3 秒极速更新，或访问 GitHub Releases 页面下载最新 APK 安装包。
- Web 端用户可直接通过浏览器访问在线地址体验，并通过浏览器菜单选择「添加到主屏幕」获得原生 App 级操作体验。
