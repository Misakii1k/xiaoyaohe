# 小药盒 1.0.17 发布说明

本次更新修复了「一键秒级更新」一直无法出现、每次升级都要重新下载完整安装包的问题。

## 修复与改进

- **秒级更新真正可用**：此前发现新版本后，应用在保存更新信息时漏掉了轻量更新包的相关信息，导致更新页面始终只显示「下载并安装」，每次都要下载完整安装包并重新走一遍安装流程。现在这些信息会被完整保留，符合条件的手机在更新页面会直接看到「一键秒级更新」按钮，点一下就能在几秒内换到新版本，不需要重新安装。
- **助手更新同样优先走轻量通道**：通过语音或对话让助手帮忙更新时，也会先尝试秒级更新，只有在轻量更新不可用或出错时才会退回到完整安装包。
- **提示说明**：从 1.0.16 升级到本版本时，仍需要下载一次完整安装包；从本版本开始，后续升级就可以享受秒级更新了。
