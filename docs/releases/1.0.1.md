# 小药盒 1.0.1 正式版发布说明

小药盒迎来 1.0.1 版本。本版本完成了移动端四屏 UI 界面与设计稿的 1:1 像素级复刻，全面打通本地 IndexedDB 真实数据库，并修复了多项关键交互与视觉细节。

## 主要更新

- **UI 1:1 像素级精准还原与设计稿对齐**：
  - **「今天」页**：对齐环形进度指示点颜色（宝蓝、翡翠绿、中灰）；药品卡片圆形 Radio 打卡按钮改为直连 IndexedDB 立即写库与清除通知，支持快速一键打卡；消除服药频次与包装单位硬编码。
  - **「药品」页**：完善顶栏「批量管理」与「AI 助手」胶囊按钮；3D 拟物指标卡搭配环境光弥散托盘；搜索与分类过滤实时联动。
  - **「库存」页**：新增「库存健康」卡片头部交互，直接唤起智能录入、近3天历史操作撤销、批量预扣与清单导出；平铺指标与余量/临期预估自适应展示。
  - **「我的」页**：修复右上角 ⚙ 按钮关闭抽屉后破坏底层主 DOM 树的严重缺陷；重构移动端「我的数据」1x3 紧凑卡片网格并直连业务路由。
- **全矢量 SVG 图标系统**：
  - 全站 100% 排除 Emoji 字符，统一采用规范一致的 Tabler / Lucide 风格 SVG 矢量图标。
- **构建与稳定性加固**：
  - 静态类型检查 0 错误，全套单元/契约/持久化测试通过，Web 生产打包顺畅。
