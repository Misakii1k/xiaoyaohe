# 小药盒 1.0.13 发布说明

本次更新重点修复了在线更新时无法使用轻量快速更新、总是重新下载完整安装包的问题，并提供了更新方式自主选择与自动保障机制。

## 新增与改进

- **优先使用轻量快速更新**：修复了更新判断逻辑与校验机制。发布日常功能改进时，手机会自动优先下载仅需几兆流量的轻量更新包，几秒内自动应用生效，不再需要每次重新下载几十兆的完整安装包并重复安装流程。
- **支持更新方式自主选择**：在软件更新页面中，检查到新版本时默认提供“一键秒级更新”按钮，同时也保留了“下载完整包”按钮，方便大家根据需要自由选择快速更新或重新安装完整包。
- **更新异常自动转接保障**：如果在下载轻量更新包的过程中遇到网络波动或文件校验异常，软件会自动提示原因并无缝切换为完整安装包下载，避免更新中断或卡在错误状态。
