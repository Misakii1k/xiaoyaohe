# 小药盒 1.0.4 正式版发布说明

小药盒迎来 1.0.4 版本。本版本同时支持 /images/edits 与 /images/generations 双生图接口，并实现自动平滑回退，全面兼容各类 AI 生图服务商。

## 主要更新

- **双模生图引擎（同时支持 /images/edits 与 /images/generations）**：
  - 支持原图修图增强模式（/images/edits，白底扫描，100% 保真文字和色彩）。
  - 支持商业展台文生大图模式（/images/generations，兼容几乎所有主流 OpenAI 格式生图服务商）。
- **智能平滑自动回退（Auto Mode）**：
  - 有拍摄照片时优先调用原图修图接口；若服务商不支持（返回 404/405/501），自动无缝平滑回退至文生大图模式，绝不中断报错。
  - 无照片但有药名时，支持直接通过文生大图生成高品质包装展台大图。
- **生图服务商配置增强**：
  - 新增「生图接口模式」配置（自动推荐 / 仅原图修图 / 仅文生大图）。
  - 预设常用生图模型（GPT Image 1、DALL·E 3、DALL·E 2、通义万相、CogView-3）。
