# 小药盒 1.0.18 发布说明

本次更新整理了药品列表的排版对齐，并对小助手界面做了一次全面改版，让对话看起来更清爽、也更好读。

## 新增与改进

- **药品列表排版对齐修复**：药品页面里每种药的名称、规格和库存标签之前会莫名居中，和下方内容对不齐。现在统一改回左对齐，一眼扫下来更整齐；批量管理里的居中卡片排版保持不变。
- **小助手界面大幅改版**：
  - 顶部区域更精简，模型和推理强度的选择收进了标题栏右侧的齿轮按钮里，需要时点开即可，不再常年占着屏幕。
  - 对话区面积明显变大，同样的手机屏幕下能多看到约一半的内容，长回复不用频繁往上翻。
  - 小助手的回答不再挤在窄窄的气泡里，改为整幅展开的浅色卡片，配合更宽松的行距，读起来轻松很多；回答下方的卡片也同步加宽，和文字自然分成两块。
  - 下方的常见问题按钮改成一行左右滑动，不会再因为问题多而把对话区越挤越小。
  - 「正在思考」的提示缩小成一个小标签，深色模式下的底色层次也一并调整过。
