# 小药盒 0.9.7 更新说明

这次移除了语音识别（按住说话、说话录药、库存语音录入），并修复了 Android 上长按输入框弹出巨大空白菜单的问题，让输入更稳、更直观。

## 你能直接感受到的变化

- 长按输入框（如 AI 服务商编辑弹窗里的名称、API 地址、密钥框）不再出现巨大的空白白块，系统自带的复制、剪切、粘贴、全选菜单能正常弹出和使用。
- 移除了语音识别：小助手不再有「按住说话」，说话录药、库存语音录入入口已去掉，设置页不再有「语音识别（腾讯云）」密钥面板。
- 原本依赖语音的录入仍可照常用：药单/药盒拍照识别、相册选图、扫描条码、手动输入都保持不变。

## 安全和稳定性

- 语音识别相关的录音权限（麦克风、音频设置）已从应用移除，应用不再请求任何录音权限。
- 修复根因：在 Android 15/16 强制全屏（edge-to-edge）下，系统栏信息被应用框架清零导致 WebView 的原生文本选择菜单渲染错乱；现已让 WebView 使用真实系统栏信息，安全区改由 WebView 原生能力承担，布局不变。
- 已填写的腾讯云语音密钥仍保留在本机安全存储中，但应用不再读取或使用；需要彻底清除的话，可在应用数据或系统设置中清理。

## 还需注意

- 若个别机型长按输入框仍出现异常，请检查并升级 Android System WebView 到最新版本后重试。
- 本次自动化环境没有可用的 ADB 设备，因此未执行真机 instrumentation；已完成 Web、单元、四视口浏览器和 Android Release 构建验证。
