# 小药盒 1.0.15 发布说明

本次更新重点修复了在药品列表页面切换后再返回时「批量管理」无法打开的问题，同时对批量管理页面和药品填写卡片的排版进行了整理，并为批量管理中的每种药品增加了图片展示。

## 新增与改进

- **修复批量管理点击无反应的问题**：修复了在底部页面之间切换或从其他页面返回后，点击药品管理顶部的「批量管理」按钮无法进入批量选择界面的问题。现在无论怎样切换页面，批量管理功能都可以正常打开并退出。
- **批量管理页面增加药品图片与排版整理**：批量管理中的每张药品卡片上方现在会优先展示大家拍摄的真实药盒照片，没有拍照时会显示药瓶图案。服药时段标签也改为横向排列，避免时段较多时把卡片拉得过长，让整个列表看起来更加整齐清晰。
- **药品编辑与录入界面内容分隔更清晰**：对新增和修改药品时的填写卡片进行了划分，药盒照片、基本档案、服药时段和库存备注分别放在独立的卡片内，输入框边缘与文字对比更加明显，方便快速核对和录入药品信息。
