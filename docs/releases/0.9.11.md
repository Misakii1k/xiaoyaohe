# 小药盒 0.9.11 更新说明

这是一次视觉与体验升级版本：上线 Gemini 3D 黏土/皮克斯风格全家福头像库，并全面规范了设置页及全站的外显文案与排版。

## 你能直接感受到的变化

- **全新 16 款 3D 全家福头像**：眼镜奶奶、白胡爷爷、男医生、女护士、爸爸、妈妈、男孩、女孩、学生、知性女性、大叔、照护员、小宝、金毛犬、三花猫与智能药盒，支持即选即换，并在「我的」个人中心与「今日」用药页顶栏联动显示。
- **关于小药盒品牌卡片重塑**：消除底层极客与代码类文案，展示精致药丸渐变 Logo、核心健康管家功能清单以及专业严谨的就医提示与免责声明。
- **外显文案全面优化**：移除普通用户不可见的 `versionCode` 构建字段，规范备份导出/恢复文案为贴合日常直觉的「导出备份文件」与「从备份恢复数据」，并人性化完善服务商提示。
- **分药向导空状态与真实记录对接**：彻底移除测试示例数据，真实读取并展示本地数据库中的今日分药操作记录。

## 安全和稳定性

- 16 款头像均为本地内置切片资源，完全离线可用，不消耗网络流量。
- 遵循本地优先原则，所有配置与服药记录完全保留在用户本地设备中。
