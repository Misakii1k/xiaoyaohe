# 小药盒 0.9.11 更新说明

本次更新上线 16 款 3D 全家福内置头像，并规范了设置页及全站的界面文案与排版。

## 主要更新

- **新增 16 款 3D 全家福头像**：内置涵盖长辈、医护、父母、儿童、宠物等 16 款头像资源，支持即选即换，并在个人中心与今日用药页顶栏联动展示。
- **关于小药盒品牌卡片调整**：展示药丸图标、核心功能清单以及就医提示与免责声明，移除开发构建字段。
- **外显文案规范**：规范备份导出与恢复文案为「导出备份文件」与「从备份恢复数据」，完善服务商配置说明。
- **分药向导展示真实记录**：移除示例测试数据，读取并展示本地数据库中当天的真实分药记录。

## 安全和稳定性

- 16 款头像均为本地内置切片资源，完全离线可用，不消耗网络流量。
- 遵循本地优先原则，所有配置与服药记录保存在用户本地设备中。
