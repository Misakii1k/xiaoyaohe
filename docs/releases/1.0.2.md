# 小药盒 1.0.2 正式版发布说明

小药盒迎来 1.0.2 版本。本版本重构了 AI 药盒生图能力，将原有的「文字特征提取后从零画新图」改为基于原图的「高保真扫描修图与增强」，保留药盒所有原始文字、色彩、图案与布局，并支持直接使用本地已拍摄/已保存的照片进行增强。

## 主要更新

- **AI 药盒扫描增强（保真修图）**：
  - 支持将药盒照片转为纯白底、均匀光照、文字清晰、透视矫正的高质量扫描图。
  - 100% 忠实保留原药盒包装上的药名、规格、商标、图案线条与色系，杜绝 AI 自行发挥或重新设计。
  - 直接支持对本地已有照片一键增强，无需重复拍照。
  - 支持在原拍摄照片与增强图之间自由切换及随时恢复原图。
- **配置与模型兼容优化**：
  - 适配 OpenAI 兼容 /images/edits 图片编辑接口。
  - 默认推荐使用 gpt-image-1 等支持图片编辑的模型。
