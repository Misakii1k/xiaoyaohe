# 小药盒 1.0.20 发布说明

本次更新改进了全屏用药提醒的解锁方式，把扫码验证改回按需开启，并为普通全屏提醒加入了向右滑动解锁。

## 新增与改进

- **扫码解锁改回按需开启**：之前版本中全屏提醒会默认要求扫码解锁，容易在急需服药或手头没有药盒时造成不便。现在改回只有在设置里明确开启「扫码解锁」时，才会要求扫描药品条码；平时未开启时不再强制扫码。
- **全屏提醒支持向右滑动解锁**：在未开启扫码解锁时，全屏提醒会保持持续响铃与醒目提醒，并在屏幕底部显示一条滑动解锁轨道。向右轻轻一滑即可解除锁定并停止响铃，随后展开「已服用」和「稍后提醒」按钮，既能防止装在口袋里意外误触关闭，也不用手忙脚乱找药盒扫码。
- **防误触退出保护**：全屏提醒在未滑动解锁前按手机返回键，会震动并提示请向右滑动解锁，避免无意中碰到底部导航栏而退出提醒。
