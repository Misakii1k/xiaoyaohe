# 小药盒 1.0.6 正式版发布说明

小药盒迎来 1.0.6 版本。本版本重构药盒 AI 展台大图提示词为正面平视无杂物大图，统一应用内输入弹窗控件并清退原生弹窗，同时深度优化设置页应用更新面板与 Markdown 发布说明排版。

## 主要更新

- **药盒生图全面重构为正面平视大图**：
  - 彻底去除导致 45 度侧角和立体透视的提示词，严格约束为正视平投（`Direct straight-on front view`），药盒正对镜头、水平居中，完整展示正面印刷。
  - 原图提取与去手持强化：有拍摄参考原图时，前置注入双语提纯指令，彻底剥离手持手指、多余杂物与杂乱背景，转换为纯白底（`#ffffff`）与柔和物理接地阴影的高保真商业产品大图。
- **统一应用内输入弹窗控件**：
  - 全局封装 `promptDialog` 统一卡片输入弹窗，替换 Android 原生灰绿 `window.prompt` 与 `confirm` 弹窗。
  - 顶部安全区自适应防软键盘遮挡，支持自动聚焦、文字全选、回车确认与 ESC 取消。
  - 设置面板操作按钮重构为 2 列等宽栅格，杜绝按钮文案折行与截断。
- **应用更新卡片与发布说明排版重构**：
  - 根除原排版因 flex 行挤压导致的标题与来源垂直单字折行缺陷，重构为独立竖向卡片架构。
  - 内置零体积依赖轻量原生 Markdown 渲染器，发布说明语义化清晰展示，进度条统一步调至品牌主色。
