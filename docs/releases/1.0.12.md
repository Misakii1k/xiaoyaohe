# 小药盒 1.0.12 发布说明

本次更新重点解决了使用其他手机应用时用药提醒无法直接全屏弹出的问题，修复了提醒响铃时两种声音同时播放的现象，并让提醒声音完整支持手机侧边闹钟音量键调节。

## 新增与改进

- **用药提醒直接全屏显示**：开启全屏提醒和悬浮窗权限后，无论手机处于桌面还是正在使用其他软件，到达用药时间时都会直接弹出全屏提醒界面，不再需要从顶部通知栏手动点击进入。
- **单一声源纯净播放**：解决了响铃时系统通知提示音与专属音乐混在一起同时响的问题。提醒通知调整为静音模式，统一只播放我们选择的专属音乐或铃声，声音更加清晰干净。
- **闹钟音量快捷调节**：提醒声音统一接入手机闹钟音频通道。提醒响起时，按手机侧边的音量加减键可以直接调节闹钟音量大小，方便随时调小或调大。
- **全屏提醒权限设置指引**：在设置页面的提醒设置中，增加了全屏显示权限的快捷开启入口与各品牌手机的设置指引，方便快速完成权限开启。
