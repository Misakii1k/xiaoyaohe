# 小药盒 1.0.16 发布说明

本次更新将软件更新提醒调整为更轻柔的方式，同时优化了药品填写与批量管理页面的排版细节，避免在小屏幕手机上出现文字断行和空间浪费。

## 新增与改进

- **应用更新提醒改为轻提醒**：发现新版本时的系统提醒不再发出声音或震动，也不会弹出遮挡屏幕的大横幅，同时去除了通知栏上多余的服药按钮。大家在使用小药盒时，应用不会弹出外部通知打扰，只在底部「我的」图标右上角安静显示小红点提示，可以在空闲时进入设置查看并升级。
- **服药计划时段标签防折行**：修复了用药计划中的「早上」、「中午」、「晚上」标签在小屏幕手机上被挤压成上下两行的问题，现在始终保持整齐的水平单行展示。
- **智能填表界面空间优化**：调整了拍照填表区域的按钮大小，不再占用过多纵向高度，同时扩大了下方的文字输入框，录入长句医嘱或药品描述时核对更加方便。
- **药品编辑向导与批量管理排版升级**：将编辑药品顶部的步骤提示重构为极简进度条，显示更紧凑且不再出现文字换行；去除了批量管理卡片左侧多余的空白区域，卡片内容居中排布更饱满，勾选药品时使用清晰的紫色边框提示，整体视觉更加清爽。
