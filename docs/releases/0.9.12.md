# 小药盒 0.9.12 更新说明

本次更新优化了扫码解锁流程、增加了 AI 助手对话历史与模型配置，并修复了批量管理页的界面排版。

## 主要更新

- **扫码解锁自动记录服药**：开启「扫码解除强制提醒」后，全屏提醒页扫描绑定的条形码或二维码会自动记录为已服用（群组提醒记录为全部已服用），并在短暂显示结果后自动关闭页面，无需手动点击「已服用」。
- **绑定扫码视图自动收起**：在「扫描生活中的已有码绑定」界面识别成功后，相机预览会自动收起，识别结果与「确认绑定」按钮直接显示在当前视口内，无需手动上滑。扫一扫认药界面的未知码结果也会自动滚动到可见位置。
- **优化扫码识别性能**：优化相机取景分辨率与识别循环节流，提升小尺寸条形码（如药盒 EAN-13 码）的识别率；原生解码器在扫描会话中复用，降低低端设备的计算开销。
- **支持保存 AI 助手对话历史**：对话记录保存在本地设备（IndexedDB）中，重新打开小助手时可以继续上下文交流。系统自动保留最近约 200 条记录，支持一键清空。
- **支持切换对话模型与推理强度**：聊天面板头部新增「对话模型」（默认跟随服务商配置，可从体检拉取的模型列表中切换）与「推理强度」（默认 / 低 / 中 / 高）下拉选项。选择仅对小助手聊天生效，服务商不支持对应参数时会自动去掉该参数重试。
- **优化卡片推送正文排版**：小助手推送结构化信息卡片时，正文不再重复卡片中的数据与清单。

## 界面修复

- 批量管理界面样式补齐：补齐提醒时段标签、行内排版与底部修改时段弹层样式；底部操作栏采用计数独占一行 + 四个按钮 2×2 排版，防止窄屏挤压溢出。
- 修复普通药品列表因样式层叠冲突导致的编辑按钮掉行问题。

## 注意事项

- 扫码自动记录仅对 Android 原生全屏提醒生效，未开启扫码验证的提醒行为保持不变。
- 对话记录仅保存在本地设备，卸载应用或清除数据时会一并移除。
