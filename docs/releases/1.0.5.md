# 小药盒 1.0.5 正式版发布说明

小药盒迎来 1.0.5 版本。本版本深度适配 Agnes Image 2.1 Flash 及同类多模态 AI 生图服务商协议，升级三级图生图与修图降级管线，并全面支持用户自定义生图配置档案管理。

## 主要更新

- **Agnes 及同类 AI 生图协议深度适配**：
  - 智能参数自适应：自动适配 Agnes 及同类聚合服务商的请求体规范，顶层设置 `return_base64: true` 与 `extra_body: { response_format: 'b64_json' }`，根除顶层参数冲突与多余字段引发的校验异常。
  - 尺寸与比例自适应：针对 Agnes 自动转换为规范的 `size: '1K'` 与 `ratio: '1:1'`。
- **原生支持多模态图生图与三级降级**：
  - 有拍摄药盒照片时，支持将原图直接以 Data URI 注入 `extra_body.image` 开启图生图修图。
  - 提供「`/images/edits` 原图修图 $\to$ `extra_body.image` 图生图 $\to$ 商业摄影纯文生大图」三级平滑降级管线，绝不中断或假死。
- **云端直链快速熔断保护**：
  - 优先拉取 Base64 图片数据；若服务商返回 Google Cloud Storage 云端直链，施加 10 秒快速超时并在网络受阻时给出清晰友好的引导提示。
- **用户自定义生图配置管理**：
  - 清退写死的静态模型模板胶囊。
  - 新增「存为新配置」与已保存配置管理列表，支持多套自定义生图配置（API 地址、密钥、模型名、接口模式）的一键快速载入与随时删除。
  - 配置密钥由系统级安全存储（Android Keychain/Keystore 与 Web 安全持久化）守护。
