设计要点

「材质化」：浮在应用之上的一层玻璃

  1. 整板玻璃：面板四边留 10px 悬浮，半透明磨砂 + 顶部高光描边，透出背后的今日页，与底栏、弹层同一材质语言。
  2. 气泡分级：用户气泡用主色渐变玻璃、助手气泡用白磨砂玻璃，层次分明但都属同一材质家族。
  3. 悬浮输入条：输入区脱离面板底边，成为独立的玻璃胶囊，是面板上唯一的“硬”元素。
  4. 环境光晕：面板内顶部两团静态青绿光晕，呼应 tokens 里的 hero 渐变；不做动画，遵守性能铁律。
  5. 性能约束：同屏 backdrop-filter 严格 ≤ 2 层（面板 + 输入条）；低端机/减弱透明度时降级为近实色。
气质：轻盈、现代、有质感。
适合：希望助手「轻若无物」又高级的方向；需注意低端机降级方案。
